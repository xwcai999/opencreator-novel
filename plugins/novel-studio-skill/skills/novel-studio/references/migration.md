# 安全迁移

使用 `migrate_project.py` 把旧 `novel-planner` 项目迁移到新目录。源目录始终只读；目标目录必须不存在或为空。

## 映射

- 保留 `设定/`、`大纲/`、`正文/` 的全部内容。
- `追踪/上下文.md` → `状态/当前状态.md`。
- `追踪/时间线.md` → `状态/时间线.md`。
- `追踪/伏笔.md` → `状态/待兑现.md`，保留原文，不自动把所有项解释为谜团。
- `追踪/角色状态.md` → `状态/角色状态.md`。
- 新建 `作品.md`、`设定/读者契约.md` 和缺失的标准目录。
- 把未映射文件复制到目标原相对路径，并写入迁移报告。
- 不复制旧 `封面/` 中的图片、清单和元数据；只在迁移报告列出路径。旧封面视为未验证，必须通过 `$codex-gpt-image` 无笔名流程重新生成。

迁移后依次运行 `validate_project.py` 和 `reindex_project.py`。迁移器只负责结构转换，不擅自修复作品事实。
