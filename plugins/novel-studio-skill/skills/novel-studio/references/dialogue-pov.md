# 对白、潜台词与 POV

## 目的与适用范围

本参考把对白和叙述视为人物在特定认知边界内争取选择权的行为。它补足章节控制卡已有的目标、压力、选择与代价，不要求每句对白都隐晦，也不把 POV 变成固定的“多写感官”清单。

本文件是创作参考，不新增项目硬门禁或第二套事实系统。章节仍使用现有 `pov` 字段；项目事实、章节状态与审查证据仍遵循 `references/project-schema.md`、`references/chapter-workflow.md` 和 `references/revision-review.md`。

## 什么时候读取

- 写或改一个以谈判、告白、审问、争执、闲聊、交易、安慰或误会为主的场景。
- 场景人物都“说得正确”、对话只负责传递设定、隐去说话人后无法辨认声音，或人物没有改变对方选择时。
- POV 跳跃、叙述者知道视角人物不可能知道的事、人物感受像作者诊断、信息投放生硬时。

## 一、对白的核心：两个人要的不是同一件事

### 场景对白契约

写对白前先用几行工作记录回答，不必逐句填写：

```text
speaker-goal: 说话者此刻想让对方做/承认/放弃什么
private-stakes: 如果对方拒绝，真正会失去什么
known: 说话者确定知道的事实
unknown-or-misread: 不知道、误解或不愿承认的部分
opening-tactic: 直接请求/讨好/试探/玩笑/威胁/沉默等起手方式
resistance: 对方为何有合理理由不配合
tactic-shift: 哪个信号会迫使说话者换策略
power-change: 谁获得了结束、定义问题、扣留信息或迫使行动的能力
new-cost: 交换后谁承担了新的代价
exit-pressure: 场景结束时留下的行动、关系或信息债
```

现有控制卡的 `active_pressure`、`counter_logic`、`choice` 和 `carryover_debt` 可以直接复用。不要把这张卡的术语写进正文。

### 潜台词不是故意说谜语

潜台词是“说出口的内容”和“此刻真正争取的东西”之间的可观察落差。建立落差时，同时给人物一个不直说的原因：害怕失去体面、没有资格发问、想保留退路、正在试探忠诚、误以为对方已经知道，或根本还没承认自己的需要。

每个关键交换可检查：

```text
表层句子：人物实际说了什么
即时目标：希望对方立刻做什么
未说出口：哪件事不能/不敢/不愿直说
对方接收：对方听见了什么、误解了什么
外部证据：停顿、改口、动作、物件、语气或空间位置
结果：信息、关系、承诺、风险或选择空间改变了什么
```

不要让所有人物都使用同样的遮掩方式。权力不对等时，弱势者可能绕开主题，强势者可能逼对方替自己说出结论；亲密关系里，沉默或过度直接也可以是潜台词。紧急场面允许人物直说，直说本身可以暴露失控、信任或时间压力。

### 试探、回避与策略变化

对话应像一次小型行动，而不是轮流发言。常见策略可以按人物需要组合：

- 直接要求、交换条件或设置最后期限。
- 先谈无关小事，观察对方是否防备。
- 用问题逼对方暴露立场，或用反问把风险推回去。
- 把私人要求包装成规则、常识、玩笑或对对方的好意。
- 提供半真信息、改变称呼、故意留白，测试对方会不会纠正。
- 沉默、离席、转移物件或让第三人在场，改变谈话的风险。
- 在一个策略失效后承认一小部分、提高代价、降低姿态或突然说真话。

起手策略失败后至少要有一次有因果的调整：对方的一个字、动作、知识漏洞或拒绝让人物重新计算。没有策略变化的长对话通常可以压缩，除非它的无变化正是人物僵化或关系冷却的结果。

## 二、话语权与场景变化

话语权不等于台词数量，也不等于声音最大。判断谁掌握局面，观察谁能：

- 决定谈什么、把问题改成什么问题。
- 让对方解释、道歉、承诺或先暴露信息。
- 中止对话、离开、召来第三方或让规则替自己执行。
- 把一句话的后果落到对方身上，而自己有退路。
- 让沉默变得昂贵，或让对方必须等待自己的回答。

场景中至少有一项发生变化：信息不对称缩小/扩大、关系距离改变、承诺成立/撤回、社会位置变化、行动选项变多/变少、某个代价被确认。若对话结束后双方仍能用同一理由、同一关系和同一选择继续，考虑删减、改为叙述，或让一次策略真正改变局面。

### 对话节拍的最小链

```text
不对称目标进入场景
    → 一方先出招
    → 对方抵抗、误解或反击
    → 出招者换策略/暴露代价
    → 信息或话语权发生偏移
    → 一方作出承诺、拒绝、让步或离开
    → 场景局部闭合，留下承接债
```

这不是固定模板。闲聊可以以关系偏移为回报，告白可以没有外部任务，审问可以让“无法得到答案”成为结果；关键是读者能感到场面结束时已经不能原样回到开始。

## 三、人物声音

### 声音由位置和选择产生

不要靠给每个人分配一个口头禅区分声音。为主要人物挑选少量稳定、可观察的特征：

- 词汇来源：职业、年龄、阶层、地域、教育、信仰或长期阅读。
- 句法与节奏：长句推演、短句截断、绕圈、重复、先问后答或只给结论。
- 直接程度：习惯命名问题、借规则说话、用玩笑遮掩，还是让对方自己领会。
- 关注对象：人物总先看价格、出口、脸色、伤口、时间、秩序或谁在听。
- 说话时的风险处理：抢答、改口、礼貌过度、装作不在乎、沉默或把问题还回去。
- 对他人的默认判断：把人当资源、证人、负担、同行、孩子、敌手或可能离开的人。

这些特征应随压力、关系和权力改变。声音不是不变的装饰：人物越害怕，可能越正式、越啰嗦、越像自己讨厌的人，也可能只剩下最短的命令。

### 隐去说话人测试

把主要对白的说话人标签去掉，检查读者能否凭词汇、句法、回避方式、关注对象和立场区分人物。无法区分时，先修复人物目标、利益和认知差异，再调整语言；不要把所有人改成统一短句、统一口语或随机添加错别字。

人物声音审查也要保留笨拙、停顿、方言感、过度礼貌和不完整表达。对白不应替人物把心理分析完整讲出来；身体反应、改口、拿错东西和答非所问常比解释更有信息。

## 四、POV：谁在看，能知道什么

### 一场戏一个主导认知入口

章节已有 `pov` 字段；在单个场景内，应明确一个主导视角人物。其他人的内心、未被观察的事实和叙述者无法确认的动机，不得直接写成确定事实。若必须换 POV，使用清楚的场景边界、载体变化或章节结构，不在同一段落无标记地跳入多个人物的头脑。

POV 不是摄像机。它决定读者以谁的欲望、恐惧、知识和误判接收材料。相同的房间，债务人先看到出口和欠条，医生先看到呼吸和手指，孩子先看到大人压低的声音；这不是加感官数量，而是改变注意力和解释。

### 叙述距离

按本场的情绪与信息需求选择距离，可在章节或场景间调整，但要有原因：

- **近距离/深 POV**：读者贴近身体、即时感受、联想和未完成的想法；适合羞耻、恐惧、亲密、判断失误和关键选择。
- **中距离**：人物过滤仍在，但允许概括时间、动作和社会背景；适合推进、对照和让读者看到人物不愿细看的部分。
- **远距离**：叙述聚焦群体、历史、制度或阶段变化；适合转场、规模感和已经被人物承受过的后果，不应突然泄露本视角不可得的内心事实。

距离变化必须改变读者与人物的关系或信息位置，而不是因为“需要解释设定”临时拉远。接近关键选择时，通常应回到能让代价被身体或行动感知的距离。

### 认知边界

写每个场景前先确定：

```text
pov-character: 谁的感知组织本场
knowledge-boundary: 视角人物可确认、可推断和不可获得的事实范围
knows: 视角人物确定知道的事实
infers: 只能从迹象推断的内容
does-not-know: 读者可以暂时不知道或比人物知道更多/更少的内容
misread-risk: 人物最可能把什么看错
distance: 近/中/远，以及本场为什么使用
```

不要用“他不知道自己正在被利用”直接替作者宣布秘密。把利用写成过度热情的帮助、被删掉的名字、突然改变的价格或一句不合时宜的关心，让人物和读者根据可见证据形成不同判断。

### 感官过滤

每场选择 1–3 个与视角人物的欲望、恐惧、职业、身体状态或关系有关的感知优先级。感官细节应能：

- 提供人物正在保护/寻找/躲避的东西。
- 改变判断或预示一个可行动的事实。
- 让环境对人物造成压力或回报。
- 暴露人物的误认、身体极限或情绪失控。

不要机械地轮换视觉、听觉、嗅觉、触觉来证明“写了感官”。无立场的风景清单不能代替视角；如果细节不影响人物的注意、解释或选择，可以删除。

## 五、信息如何进入正文

### 先感知，再解释，再修正

信息投放优先遵循人物在场的顺序：

```text
可感知证据 → 视角人物的即时解释 → 他人/后果修正解释 → 选择空间改变
```

信息可以通过动作、物件、称呼、停顿、价格、伤势、环境反馈、他人反应或规则执行进入。解释只有在人物此刻确实需要推理、记忆或判断时才出现。

为每条重要信息决定读者位置：

- 读者和 POV 同时发现：制造探索或共同理解。
- 读者早于 POV 知道：制造悬念、担忧或反讽，但证据必须已在正文中可见。
- POV 早于读者知道：制造隐瞒、误读或亲密；不能靠不自然的“突然想起”长期扣留。

不要把控制卡、作者解释、世界词条或“读者应该明白”直接放进正文。若信息没有改变人物的判断、关系、承诺、风险或选项，它通常还没有叙事功能。

### 内心叙述与自由间接表达

近距离叙述可以让人物的词汇和价值判断渗入叙述，但不要每次都写“他想”“他意识到”或作者式心理诊断。让人物的比较、命名、否认、身体反应和记忆偏差承担一部分心理信息；自由间接表达仍必须服从视角人物能知道和会这样理解的边界。

人物自欺时，叙述可以让读者从动作、语气和结果看出裂缝，不必由全知声音替他宣判。若采用不可靠视角，要保持可复核的迹象，并让误判在后续行动中产生代价。

## 六、对话与 POV 的联动卡

复杂场景只需补以下最小记录：

```text
pov: 视角人物
distance: 本场叙述距离
sensory-filter: 此人物最先注意的 1–3 类信号
speaker-goals: 各方当下目标
knowledge-gap: 各方知道/误解/隐瞒的差异
subtext-risk: 谁不能直说什么，为什么
tactic-shift: 哪个可见信号会让谁改变策略
power-shift: 谁获得或失去定义问题、扣留信息、结束谈话的能力
information-delivery: 本场让读者何时知道什么
choice-and-cost: 场景让谁作出什么选择，放弃什么
local-closure: 本场完成的局部变化
carryover-debt: 留给后续的关系、行动或信息债
```

这张卡是创作输入，不是正文格式，也不是要交给首次读者的解释。它可以直接映射现有 `reader_reward`、`active_pressure`、`human_cost`、`counter_logic`、`choice`、`local_closure` 和 `carryover_debt`。

## 七、修订与验收

### 根因路由

- **`outline`**：场景没有不对称目标、信息位置或可兑现的变化。
- **`character`**：人物没有私人风险、声音来源、误判或不愿直说的内容。
- **`scene`**：有目标但没有阻力、策略转换、话语权变化或局部闭合。
- **`language`**：解释腔、同声、标签化情绪、模板句或不必要的 POV 跳跃遮住了场景。

沿用 `references/revision-review.md` 的证据顺序和轮次边界。修订优先在最小范围内改动策略、信息入口、动作或代价，不用同义词轮换、随机停顿或整章洗稿制造“人味”。

### 最小验收清单

- [ ] 场景中的每个主要说话者都有此刻的目标和拒绝代价。
- [ ] 至少一次试探、回避或策略变化由对方的行动触发。
- [ ] 话语权变化可通过主题控制、信息扣留、沉默、称呼、空间或后果观察到。
- [ ] 关键对白的表层内容与真实争取之间有可理解的落差，紧急或亲密场景可合理直说。
- [ ] 隐去标签后主要人物的词汇、节奏、关注对象和回避方式可区分。
- [ ] 一个场景只有一个主导 POV；叙述距离、知识边界和感官过滤有明确原因。
- [ ] 重要信息通过可感知证据进入，并改变判断、关系、风险或选择空间。
- [ ] 场景结尾留下改变后的局面或承接债，而不是作者式心理总结。

对白、潜台词和 POV 的目的不是让人物永远含蓄、让叙述永远贴身，而是让读者感到：人物正在用自己能知道、能说和不敢说的方式争取下一步。
