# 完本文学复评

## 触发与停止条件

终章正文完成后、标记“全本质量通过”或制作最终发布包之前，必须执行本门禁。以下证据均不能替代它：

- 所有章节逐一 `accepted`；
- 项目校验 0 错误、0 警告；
- 待兑现项归零；
- 终章或卷末局部审查 PASS；
- 字数、章节数、正文哈希和投稿 TXT 完整。

这些证据证明项目制作完整，不证明全书在连续阅读中成立。硬错误或阅读阻断（包括有复现证据的结构阻断）未清零时，不得标记“全本质量通过”。用户可以明确选择带风险发布并记录理由，但状态必须写为“用户覆盖发布/风险保留”，不能把覆盖记录写成质量 PASS。

## 1. 冻结同一全文版本

1. 按真实阅读顺序从权威章节生成只含章名与正文的纯 TXT，不含 frontmatter、控制卡、状态、报告或待兑现说明。
2. 记录章节范围、canonical 正文字数和纯正文 SHA-256；运行项目校验和待兑现审计。
3. 当前篇幅与用途所要求的全部隔离审稿者必须读取同一份冻结正文。正文 body 发生任何修改后，旧全本报告和评分立即失效。

## 2. 主 Agent 先建立全书状态地图

主 Agent 亲自顺序复读全文，以每 5—10 章或既定卷界为窗口记录：

- 主角处境和外部目标；
- 关系与权力迁移；
- 资源、债务、场地和权限变化；
- 人物选择与持续代价；
- 标题承诺和读者契约的阶段兑现；
- 新增威胁、谜团、案件和最终处置；
- 窗口结束后不可逆的变化。

不得把大纲意图、状态台账或逐章 PASS 当作正文已兑现的证明。地图只供主 Agent 裁决，不泄露给盲审者。

## 3. 适用的隔离审查

标准、扩展、目标 5 万字以上、投稿/出版或详细评分模式使用以下三类审稿者；各审稿者并行、互不读取报告，且只写报告不改正文：

### 首次读者

- 输入：冻结纯正文、目标读者画像；可在读完后核对读者契约。
- 输出：一句话主线、阶段地图、最想继续读与首次想跳读位置、人物记忆点、回报链、结尾满意度。
- 必答：首次能够预测下一章仍用同一解法的位置。

### 连续性与文体审查

- 输入：冻结纯正文、权威当前状态/时间线/关系/待兑现项，以及只读趋势证据。
- 输出：人物身份、时间、数量、资金、资源、权限与未结案威胁；执行 `structure-similarity-review.md` 的三个尺度审查，并单列绑定纯正文哈希的 `PASS / WARNING / BLOCK`。
- 指标只定位回读，不得自动判文学质量。

### 出版／投稿编辑

- 输入：冻结纯正文、规范书名、作品定位和读者契约，不读取大纲、状态、旧报告或趋势指标。
- 输出：标题和前三章留存、每个阶段是否换挡、中段流失、人物商品性、高潮与终章兑现、发布建议。
- 必须区分“阶段性卷末成立”与“全本终局成立”。

目标 5 万字以上、显式投稿/出版或用户要求详细全本评分时固定执行三类审查。`light/short` 且非投稿、用户只要求简要完本判断时，可缩放为两名隔离审稿者（首次读者、连续性/文体），由主 Agent 独立承担编辑裁决；不得省略纯正文冻结、结构雷同结论和角色上下文隔离。

## 4. 全本强制检查项

1. 前三章和前十章是否兑现标题、首笔代价与继续阅读理由。
2. 每个阶段是否改变人物处境、关系/权力、资源/场地、外部目标、任务/信息或选择空间。
3. 按 `structure-similarity-review.md` 比较相邻 3 章、阶段窗口和全书；检查前期有效的题材发动机是否在后期退化为唯一模板。
4. 主角及关键配角的个人代价是否持续，是否退化为正确流程主持人、递材料者或签字席。
5. 所有重大威胁、案件、资源和承诺是否有正文可见的处置；“已纳入制度”不能替代实物、责任与后果结案。
6. 身份、宗门、时间、货物、批次、编号、金额、资金性质和支付顺位能否跨章核对。
7. 终章是否由人物选择和场景挣得，还是在同一章用总结集中宣布多条闭环。
8. 读者契约的中段变局与终局承诺是否在正确阶段出现；终章补充说明不能冒充中段已经发生。
9. 当前包装是全本、单卷还是第一季；残余钩子是否与该包装相容。

## 5. 主代理裁决

主 Agent 必须回到冻结正文和权威状态逐项核实当前篇幅与用途所要求的全部隔离报告，不得按平均分、多数票或校验结果直接放行：

- 审稿者误读设定或数字时驳回该项，并记录正文证据。
- 多份报告指向同一读者影响但根因不同，定位最早的 `outline/character/scene/language` 根因。
- 只有明确正文冲突进入硬错误；可由两种合理解释成立的问题列为高风险歧义，不武断升级。
- 结构雷同必须有结构签名/人工测试与独立盲读反应共同支持。

## 6. 输出与发布档位

`standard/extended`、目标 5 万字以上、投稿/出版或用户要求详细评分时，全本报告必须包含：

- 总分、分卷/阶段评分和维度评分；
- 一句话总评、最强章节或窗口、首次流失点；
- 确定性硬错误、阅读阻断、工艺警告；
- 审稿分歧与主 Agent 裁决；
- 最值得返修的 3—5 项及最小受影响范围；
- 以下唯一发布档位之一：
  - **直接发布**：无硬错误或阅读阻断，仅有可接受工艺警告；
  - **精修后发布**：结构与终局成立，剩余为局部场景、语言或可核对口径修订；
  - **结构返修后发布**：阶段同构、人物机制、未结案主线或终局因果需要跨章调整。

总分不得掩盖门禁：高分作品仍可因确定硬错阻断，低分作品也不能在没有正文证据时被迫重构。

`light/short` 且非投稿、用户只要求简要判断时，最小报告保留：冻结正文范围与哈希、结构雷同裁决、硬错误与阅读阻断证据、首次预测/跳读点、根因、最小返修范围和发布档位；总分、分卷评分与完整维度表按用户需求生成。

## 7. 返修后复验

- 硬错误最小修正后，重跑受影响连续性检查和全本数字/身份检索。
- 结构返修改变任何正文 body 后，旧的适用隔离报告全部失效；重新生成纯正文、哈希，并按当前篇幅与用途重跑两类或三类隔离审查。
- 同一根因层最多连续返修两轮，第三版仍 BLOCK 时停止盲改，向上回到大纲、人物或场景机制。
- 只有新冻结版本通过，才能更新完本质量状态与最终发布包。
