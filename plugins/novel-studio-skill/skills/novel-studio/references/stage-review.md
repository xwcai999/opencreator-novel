# 跨章阶段审查

## 触发频率

- 短篇：中点与终稿。
- 中篇：每 5–6 章，篇章结束时可提前合并执行。
- 长篇：每 8–10 章及每卷结束。

逐章接受解决局部问题，阶段审查负责发现累积偏移。不要用阶段审查重新否定已经确认的正文事实。

阶段审查先做当前范围的纯 TXT 盲读：阶段窗口至少覆盖整卷；终稿必须覆盖全本（短篇的整卷即全本）。正文按实际阅读顺序拼接，只向盲审者提供正文 TXT 与目标读者画像，不提供设定、大纲、控制卡、状态、旧报告、扫描指标或待查问题。

## 检查维度

1. 读者回报是否长期偏到单一类型，核心契约是否仍在兑现。
2. 对白、场景交互和身体行动是否持续下降，说明与分析是否持续上升。
3. 章节是否重复同一“目标—阻力—方案—成功”或同型章末；若重复时人物处境、关系、代价和选择空间不变，列为阅读阻断候选而非单纯节奏警告。
4. 主角的个人代价是否消失，只剩职业任务或抽象责任。
5. 配角的词汇、利益、回避方式和选择是否同质。
6. 副线或关系线是否变冷，待兑现项是否只有登记没有进入场景。
7. 中段变局是否真正改变处境，而非只增加任务数量。
8. 经营题材的数据和流程是否改变了人的尊严、时间、关系、身体、金钱或选择空间。
9. 对每个非终态待兑现 ID 检查首次出现、最近推进、兑现窗口与禁止揭露项；区分“已埋设”“阶段回响”和“最终兑现”。超过窗口必须先兑现、废弃或重排，不能继续写下一章。
10. 标题承诺与主线目标是否及时落锚；盲读者能否复述主角要什么、付出什么、阶段回报如何兑现，而不是到中后段才首次知道方向。
11. 专业术语、数字和流程是否落到具体人物后果；若只增加说明而不改变人物的时间、尊严、关系、身体、金钱、安全感或选择空间，且造成方向丢失，列为阅读阻断候选。
12. 隐去说话人后，主要人物的词汇、句法、回避方式和立场能否区分；若同声遮蔽了谁在作决定，结合纯 TXT 盲读升级，不用“更口语”作唯一修复目标。
13. 叙述或对白是否出现审查解释泄漏：重复复述已演出的结论，或用控制卡/门禁/读者说明替代场景中的选择与后果；除非是明确成立的元叙事，否则按正文证据处理。

阶段审查前运行：

```powershell
python scripts/expectation_ledger.py --project-root <项目目录> --target-chapter <下一章号>
```

报告中的冷线必须逐项给出“本阶段推进、继续冷藏及理由、调整窗口、废弃”之一，不得只登记不裁决。

## 纯 TXT 盲读与可复述性门禁

盲读者在查看任何元数据前，必须留下四项记录：

1. 一句话主线：主角、核心目标、主要代价、标题承诺的回报。
2. 阶段地图：每个阶段或章节组的一句事件与处境变化。
3. 阅读阻断点：首次困惑、想跳读、无法区分说话人或无法解释专业数字的位置，并引用正文。
4. 回报链：本阶段已经兑现的回报、仍在等待的回报，以及读者为何继续读。

可复述性只检查方向和承诺是否可感知，不要求复述所有细节。若无法复述且证据指向目标锚点后置、跨章同构、人物同声、专业信息未产生人物后果或解释泄漏，阶段状态阻断；有意留白、复杂题材和实验性结构需先证明读者仍有可感知的驱动，不能以“复述不完整”单独判败。

## 分析器使用

运行：

```powershell
python scripts/analyze_prose_trends.py --project-root <项目目录> --json
```

也可以分析隔离文件或目录：

```powershell
python scripts/analyze_prose_trends.py <章节1.md> <章节2.md>
```

工具输出对白占比、段落节奏、分析/流程词、重复句式和章末结构趋势。它不修改任何文件，不给文学总分，也不直接判定通过或失败。

逐章真实性候选另用：

```powershell
python scripts/scan_authenticity_artifacts.py --project-root <项目目录> --chapter <章节号> --json
```

真实性扫描定位单章内的流程泄漏、模板化解释、抽象/流程聚集、通用微动作和固定章末；跨章分析器判断这些倾向是否累积同质化。两者都不检测文本来源、不自动改写，普通命中只能进入工艺警告；只有具体正文回读与纯 TXT 盲读共同证明上述阅读阻断时，才能升级到第二层，`workflow-leak` 仍按硬门禁处理。

指标、比例和趋势图只负责定位需要回读的窗口，不设阈值直接判定文学质量；人工/模型需说明题材语境、人物选择和读者影响。

## 证据升级规则

1. 用指标找到变化最大的章节或窗口，但不把数值当作结论。
2. 回读具体段落，确认它是题材需要、人物声音，还是流程化/说明化问题，并记录人物后果。
3. 对同一正文版本先做两名独立纯 TXT 盲审。若在门禁结论、根因、证据解释或是否通过上出现实质分歧，自动邀请第三名盲审；第三名不得看到前两份报告或争议提示。
4. 只有正文证据与盲读反应相互支持时，才把趋势升级为阅读阻断；三审仍分歧时由主 Agent 按权威事实与证据裁决并记录理由。
5. 修订应针对 `outline`、`character`、`scene` 或 `language` 根因，不以“把比例调回去”为目标；审查意见不得补进正文。

## 分歧后的返修层级

若同一阻断在两轮修订后仍复现，或同时影响两个以上章节，停止单句、段落和同义词补丁。先定位最早出现的根因及受影响场景簇，重构目标锚点、人物选择、处境后果或信息承载方式，再对受影响整卷/全本重新纯 TXT 盲读。最多三轮后仍未通过，停在草稿状态并向主 Agent 报告根因，不把“读者应理解”或其他审查解释塞回正文。

## 输出

阶段报告包含：时间窗口、趋势证据、具体章节位置、纯 TXT 复述记录、读者影响、根因假设、两审/第三盲审分歧与主 Agent 裁决、建议改动层级和无需处理的合理偏移。报告属于派生物，不写入正文和权威状态。
