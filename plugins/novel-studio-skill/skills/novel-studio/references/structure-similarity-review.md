# 章节结构雷同审查

## 目的与边界

本审查发现“换了人物、地点或道具，章节仍按同一方法展开”的跨章同构。它不以重复词、固定术语、类型仪式或相同叙述视角直接判错；职业文、单元案、升级文和经营文允许稳定仪式，只要人物选择、阻力行为、解法和不可逆结果持续改变。

不要设置机械相似度阈值。工具计数和结构签名只负责定位，正文证据、独立盲读反应及阶段状态变化共同决定是否阻断。

## 三个审查尺度

1. **相邻尺度**：每完成一章比较最近 3 章，判断读者是否已能预测场景展开和章末落点。
2. **阶段尺度**：阶段或卷末比较该窗口全部章节，检查同一解法是否反复替代人物推进。
3. **全书尺度**：完本时比较所有阶段，检查前期有效的题材发动机是否在中后期退化为唯一场景模板。

相邻审查不能替代阶段审查；近三章暂时不同，也可能在十章窗口内轮换重复两套模板。阶段窗口需向前重叠读取至少 2 章，避免同构簇被窗口边界切断。

## 章节结构签名

主 Agent 在工作记录中为每章提取以下字段，不把签名或怀疑点交给盲审者：

| 字段 | 要回答的问题 |
| --- | --- |
| 外部目标 | 本章人物试图改变什么现实？ |
| 压力来源 | 谁或什么主动制造阻力？ |
| 决定者 | 谁作出改变局面的选择？ |
| 主要场域 | 冲突主要发生在何种空间和互动形态？ |
| 推进载体 | 现场行动、关系谈判、证据、训练、经营、战斗或其他什么承载推进？ |
| 核心解法 | 人物最终靠什么越过阻力？ |
| 个人代价 | 谁失去钱、时间、身体、资格、关系、安全感或选择权？ |
| 不可逆结果 | 章末有什么不能轻易恢复原状？ |
| 承接功能 | 下一章为何必须发生，选择空间如何变化？ |

字段措辞相近不自动构成同构。重点比较“压力—选择—解法—代价—结果”的因果组合。

## 四项人工测试

### 1. 换皮测试

隐去专有名词、数字和道具后，若多章仍可复述成同一个流程，例如“发现异常材料→权威解释边界→多人会签→封存→出现下一份残件”，记录同构候选。

### 2. 删章测试

假设删除其中一章，仅把新信息补进下一章：如果人物关系、资源状态、选择范围和情绪回报几乎不变，该章可能只是重复传递信息。不得真的删正文，只在审查报告中记录推演。

### 3. 结果测试

要求用一句话回答：“经过本章，谁今后不能再像以前一样做什么？”若连续多章只能回答“线索更多、期限更短、缺口仍在、再次确认边界”，阶段动量可能停滞。

### 4. 预测测试

纯 TXT 盲读者在不知道结构签名和怀疑点的情况下，记录首次能够预测下一章解法或想跳读的位置。只有这种反应与正文结构证据相互支持，才从工艺警告升级为阅读阻断。

## 裁决层级

### 允许的类型仪式

- 相同职业流程承担题材辨识度，但每次由不同人物作出决定。
- 解法相似，却造成不同且不可逆的关系、资源或身份后果。
- 有意复沓用于喜剧、恐怖、仪式或主题回响，盲读者仍获得新的情绪与选择变化。

### 工艺警告

- 场景入口、说明顺序或章末句型重复，但人物状态仍有实质迁移。
- 同类案件过密，盲读者感到熟悉，却尚未准确预判全部展开。

### 阅读阻断

同时具备以下证据时阻断后续提交或完本放行：

1. 换皮测试或删章测试成立；
2. 独立纯 TXT 盲读者指出相同位置的可预测、跳读或方向停滞；
3. 连续章节的决定者、核心解法、个人代价和不可逆结果没有实质变化。

## 根因与返修路由

- `language`：只有句式、段落、章末措辞重复，人物与结果不同；做局部语言修订。
- `scene`：地点和道具不同，但互动顺序、决定者与解法相同；重组场景，让阻力主动行动或改变决定权。
- `character`：配角只递材料、签字或认可主角，无法作出自身利益选择；恢复其欲望、拒绝和损失。
- `outline`：多章只增加线索或任务，删除任一章不改变状态；合并章节、提前变局或让阶段目标换挡。

返修不以强加战斗、事故、反派、反转或随机牺牲制造差异。先改变因果功能，再调整语言；结构阻断不得用同义词替换或增加解释解决。

## 报告格式

`standard/extended`、卷末和全本报告至少包含：

1. 审查范围与三个尺度；
2. 章节结构签名表；
3. 首次同构候选与正文证据；
4. 换皮、删章、结果和预测测试；
5. 允许的类型仪式；
6. 工艺警告与阅读阻断分层；
7. 最早根因章节和 `outline/character/scene/language` 路由；
8. 最小返修范围与必须重新盲读的范围。

`light/short` 且非投稿、用户只要求简要判断时，阶段、卷末和全本均允许缩为：候选章节结构签名、首次预测/跳读证据、状态迁移、裁决和返修范围；没有同构候选时不必展开完整四项测试。`standard/extended`、投稿/出版、详细全本评分或任何 `BLOCK` 候选仍使用完整格式。

报告必须单独给出 `PASS / WARNING / BLOCK`；可以作为连续性/文体报告中的独立章节，但不得被综合总分或其他审查结论代替。阶段报告同时记录目标阶段范围、为跨边界比较额外读取的重叠范围，以及覆盖全部实际读取正文的 SHA-256。阶段、卷末或完本门禁缺少这项产物时直接视为未完成，不得放行。任何正文 body 修改都会使包含该章的相应窗口及全本结构雷同结论失效；只改 frontmatter、索引或报告不触发失效。
