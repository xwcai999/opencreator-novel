# 节奏、类型兑现与场景组织

本文件补充章节控制卡的使用方法，不新增权威状态字段。正文与现行状态仍是事实来源；**reader_reward**、**active_pressure**、**human_cost**、**counter_logic**、**choice**、**memory_point**、**local_closure** 和 **carryover_debt** 仍是规划输入，不得复制成第二套事实系统。

## 一、先确认驱动，再安排节奏

题材驱动是读者继续阅读的主要原因，不是书名标签，也不是固定结构。每本书选择一个主驱动，最多一个副驱动。主驱动决定本章主要回报，副驱动只在确有因果时着色；不要求一章同时兑现七类回报。

“节奏快”不等于事件多、句子短或每章反转。节奏是读者对“人物正在推进什么、付出了什么、下一步为何发生”的感知速度。安静章节只要完成一次理解、关系偏移、生活阶段转换或任务进展，同样可以有节奏。

## 二、因果升级不是声音变大

可用的最小因果链是：

现状锚点 → 压力与欲望相撞 → 具体选择 → 立即后果 → 延迟代价或收益 → 状态改变 → 下一次需要或选择

每次推进至少回答：

- 谁因为这次选择失去了什么，或获得了什么？
- 哪个选项因此关闭、变贵或变得不可逆？
- 变化落在人物的时间、尊严、关系、身体、金钱、安全感或选择空间中的哪一处？
- 下一步是由新的状态逼出来，还是作者为了继续而临时添加？

优先只抬高与主驱动有关的轴：

| 升级轴 | 适合表现的变化 | 误用信号 |
| --- | --- | --- |
| 约束 | 时间缩短、资源减少、规则变严 | 只增加更大的敌人或更响的警报 |
| 暴露 | 私人秘密、立场、失误或关系被看见 | 用解释直接宣布人物已暴露 |
| 代价 | 选择要放弃的利益变得具体 | 事后用一句“他很后悔”结算 |
| 不可逆性 | 说出口、签下、离开、伤害、承诺 | 用反转撤销已经发生的后果 |
| 关系压力 | 信任、距离、承诺或立场改变 | 所有人无缘无故争吵 |
| 认知不确定 | 新证据迫使人物修正判断 | 只有名词增加，选择不变 |

没有选择、后果或状态变化的段落，通常应删去、压缩成概述，或回到大纲补足因果。低声量的选择仍然可以升级；例如一个人没有拨出电话，可能比一次追逐更改写关系。

## 三、场景与概述的切换

场景不是“写得更细”，概述也不是“写得更快”。两者由读者是否需要亲历某个不确定的选择来区分。

| 保留为场景 | 压缩为概述 |
| --- | --- |
| 人物必须拒绝、承诺、谈判、撒谎、冒险或承担后果 | 时间流逝、重复练习、已知结果的日常 |
| 关系态度发生变化，潜台词决定下一步 | 旅行、换季、恢复、搬迁等过渡 |
| 新证据会改变判断，读者需要跟随误读或验证 | 背景资料已经被确认，只需留下可检索事实 |
| 一次体验本身就是读者回报，删掉会失去记忆点 | 多次同型尝试没有新增选择或状态 |
| 失败会改变人物的身体、尊严、资源或选择空间 | 结果明确，过程没有新的阻力、代价或人物差异 |

切换规则：

1. 先在概述中交代时间或重复过程，再在真正出现不确定选择的地方落入场景。
2. 如果概述句子里藏着“决定、承诺、翻脸、发现、拒绝或付出”，那一句通常应该扩成场景。
3. 场景完成 **local_closure** 或只剩重复动作后退出；不要为了保留“现场感”继续写已知结果。
4. 概述结束必须留下新的状态、关系余波、资源变化或 **carryover_debt**；不可用“几天后，一切照常”跳过因果。
5. 不在一个段落里频繁来回切换视角和详略来制造假节奏。切换应服务于选择、回报或状态变化。

一个实用判断是：若读者需要知道“人物当时怎样选择”，写场景；若读者只需知道“这段时间发生了什么变化”，写概述。

## 四、张弛与章际能量

下面五种能量动作是可选工具，不是每章必须按顺序执行：

- **点火**：让目标、需要或个人代价变得可感知。
- **施压**：让两个真实利益不能同时满足，迫使人物选择。
- **落地**：展示选择的立即后果，并完成本章局部回报。
- **回响**：让关系、体验、主题或持续代价在安静处显影。
- **转向**：由已改变的状态产生下一步需要、目标或主动放弃。

章节可以从任一动作开始，也可以只完成其中一两个。不要把“回响”误写成复盘，把“转向”误写成预告。章节结束时检查：

- 本章的 **local_closure** 是否已经给出读者可感知的回报？
- **carryover_debt** 是否来自已经发生的选择，而不是作者硬留问题？
- 下一章的方向是否由本章状态改变自然产生？

章际能量可以连续，也可以故意反差：

| 前章留下的东西 | 后章可采用的兑现方式 |
| --- | --- |
| 外部胜利、人物受损 | 用身体、关系或尊严的余波承接，不必马上再加危机 |
| 信息揭露、判断被推翻 | 让人物重新解释旧行动，或在新信息下作出小选择 |
| 关系承诺、边界改变 | 用一次具体的履约、躲避或试探兑现 |
| 体验片段、情绪抵达 | 用生活状态改变或阶段告别承接 |
| 任务完成、资源到手 | 让新资源带来责任、分配或下一阶段，而不是重复同一任务 |

张弛的最低要求不是“紧张—放松”的固定曲线，而是读者能区分本章与前章的处境、回报或选择空间。连续章节若都使用“发现问题—讨论方案—执行成功”，即使每章都有新名词，也属于能量和事件中心同构。

## 五、七类驱动的差异化兑现

| 主驱动 | 读者期待的回报 | 适合的因果机制 | 场景/概述偏重 | 避免的伪兑现 |
| --- | --- | --- | --- | --- |
| **growth** 成长 | 能力、认知、身份或自由发生可见变化 | 受压尝试 → 反馈或失败 → 放弃旧办法 → 付代价作出新选择 | 测试、误判和转变写成场景；重复练习可概述 | 用等级、资格或宣言代替真实改变 |
| **relationship** 关系 | 距离、信任、承诺、立场或默契改变 | 欲望与边界相撞 → 说出/隐瞒/履约 → 对方重新回应 | 关键互动、沉默和动作写成场景；相处时日可概述 | 为制造节奏强塞争吵、误会或背叛 |
| **business** 经营 | 资源、收益、口碑或秩序改变，并落到具体人的处境 | 资源取舍 → 制度或交易改变 → 某个人承担收益与损失 | 谈判、分配和失败余波写成场景；重复流程可概述 | 只写指标上涨，不写人的时间、尊严、关系或选择空间 |
| **information** 信息 | 对事实的理解被获得、验证、修正或揭露 | 线索 → 假设 → 检验/误读 → 更新模型 → 揭露 | 不确定证据与判断写成场景；已确认资料可概述 | 只堆世界名词，或没有公平证据就突然揭晓 |
| **experiential** 体验 | 一段具体生活质感、情绪抵达或阶段闭合 | 感官/习惯 → 微小偏移 → 人物对生活的感受改变 | 不可替代的相处和感受写成场景；季节与重复日常可概述 | 用空泛氛围代替人物处境变化 |
| **thematic** 主题 | 人物以有代价的行动回答价值问题 | 两个真实价值不能兼得 → 选择 → 后果迫使立场变化 | 选择及其关系后果写成场景；背景讨论可概述 | 让人物发表正确观点，替代行动与损失 |
| **quest** 任务 | 目标进入新阶段、取得成果、调整或主动放弃 | 目标 → 障碍 → 策略选择 → 取得/失去成果 → 新阶段 | 不可逆障碍和成果写成场景；旅行与重复准备可概述 | 为延长篇幅添加无关支线或强制谜团 |

只有 **information** 主驱动或用户明确要求悬疑时，才强制维护谜团、线索和揭露账本。其他驱动可以使用秘密或未知，但它们必须服务于人物选择，不得自动变成悬疑结构。

## 六、写前与写后检查

写前从已有章节控制卡补充四个问题，不另建状态文件：

1. 本章的 **reader_reward** 属于哪一类，读者会在何处看见它？
2. **choice** 放弃了什么，立即后果与延迟代价分别是什么？
3. 哪一段必须亲历，哪一段只需知道结果？切换后留下了什么状态？
4. 本章结束的 **local_closure** 与 **carryover_debt** 如何区别前后章？

写后若出现以下证据，按四层根因路由，而不是先润色：

- 读者说不清主角要什么或本章回报：先查 **outline**，包括主/副驱动和读者契约。
- 目标清楚但人物总选最优、没有放弃项：查 **character**，补足欲望、羞耻、承诺或私人利益。
- 人物有选择但场景没有后果、两章事件中心同构，或关键选择被概述吞掉：查 **scene**。
- 因果成立但文本用总结、抽象名词、同声对白代替在场证据：查 **language**。

两次定向修订仍复现同一层问题，或问题已跨多个章节，就上移到更早的根因层；第三轮仍不通过时停在草稿并报告根因，不用同义词轮换、加危机或固定章末钩子掩盖问题。
