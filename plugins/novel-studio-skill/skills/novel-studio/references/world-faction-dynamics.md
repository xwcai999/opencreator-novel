# 世界与势力运转

## 目的与适用范围

本参考把“世界观资料”转化为正文中的约束、行动和后果。它服务于规划、章节写作和修订，不是百科资料收集器，也不要求每部小说建立庞大的势力网。

只有当地点、制度、资源、技术、信仰、阶层或组织会改变人物的可行选择时，才把它纳入本模块。家庭、公司、学校、社区、帮派、国家、宗族和线上群体都可以是“势力”；名称和规模不重要，持续影响选择的能力才重要。

本文件是创作参考，不新增项目硬门禁或第二套事实系统。项目仍以 Markdown 正文和 YAML frontmatter 为唯一权威数据，事实裁决遵循 `references/revision-review.md` 的证据顺序。

## 核心转化链

世界不是背景板，势力也不是角色名单。写作前要能追踪下面这条链：

```text
世界规则/稀缺条件
    ↓ 限制或打开可行行动
势力的利益、资源与约束
    ↓ 形成持续行动和内部争论
势力关系变化与离屏后果
    ↓ 把压力落到具体人物
人物采取策略并付出代价
    ↓ 改变规则的执行、资源分配或势力关系
下一场的选择空间已经不同
```

如果一条设定不能改变“谁现在能做什么、不能做什么、做了要失去什么”，它暂时只是资料，不应挤占正文上下文。

## 什么时候读取

- 规划总纲、卷纲或细纲，且主线依赖制度、资源、势力、地域差异或社会关系时。
- 写作或续写一章，且本章的 `active_pressure`、`counter_logic`、地点行为或可用选择受规则/势力影响时。
- 修订中发现冲突像“作者安排”、阻力方只为主角服务、世界名词多但处境不变时。

不要为了一个不影响选择的名词加载整套世界观。优先读取 `continuity-sources` 指定的规则、地点、势力和关系文件，再补充本场景真正用到的上下文。

## 一、把世界规则写成约束

### 规则的最小问题集

每条真正会进入正文的规则，至少回答：

1. **范围**：它在何处、何时、对谁成立？是自然规律、制度规定、资源现实、社会禁忌，还是某种知识边界？
2. **可行行动**：它允许什么、阻止什么、让哪条路变贵或变慢？
3. **执行机制**：谁或什么让它生效？人物怎样知道、误解或利用它？
4. **代价与后果**：违反、绕开或遵守分别会让谁付出什么？后果是否能落到时间、身体、金钱、关系、声望、安全或选择空间？
5. **例外与变化**：例外由谁掌握，为什么不是人人可用？什么事件会改变规则的执行，而不是凭空取消规则？

只回答“它是什么、从何而来、有哪些分类”仍然是百科资料。历史和分类只有在解释今天的约束、利益或盲点时才保留。

### 规则卡（按需填写）

```yaml
rule-id: night-permit
scope: 某区域/某时段/某类人
visible-form: 人物在场时看见的标志、流程或禁令
allows: 可行但有条件的行动
forbids: 不能直接做的行动
cost: 遵守规则的现实价格
enforcement: 谁/什么会执行，如何被发现
exception: 谁有例外资格，例外的交换条件
failure-consequence: 违规或绕开后的具体后果
beneficiary: 规则持续为谁保留什么
burden-bearer: 谁承担时间、风险或尊严损失
scene-entry: 本章通过什么动作、物件、对白或后果呈现
change-trigger: 什么已发生事件会改变执行方式
```

字段是思考提示，不是必须全部写入项目文件。不要把 `visible-form`、`scene-entry` 的解释整段塞进正文；让人物在排队、被拦下、改口、付钱、错过时间或承担后果时让读者理解规则。

规则进入场景通常表现为阻断、定价、交换、误用或执行方式变动。一场戏至少要让规则改变一次选择、价格、风险或信息位置；只把规则解释一遍不算场景功能。

## 二、势力不是设定条目，而是持续行动者

### 势力最低模型

为会影响本书主线的势力建立以下模型。小型作品可以把家庭、同事圈或一段关系视作微型势力；不需要为了凑数量增加组织。

```yaml
faction-id: harbor-guild
name: 势力名称
public-goal: 对外宣称要实现什么
true-interest: 内部必须保住的利益、权力、秩序或生存条件
resources: 可调动的人、钱、信息、资格、暴力、信用、地点或时间
constraints: 自身缺什么，受哪条规则、债务、舆论、内部利益或外部力量限制
methods: 通常如何施压、谈判、收买、保护、拖延或转移风险
red-lines: 什么损失会迫使它改变策略；什么事不能公开越过
internal-factions: 内部互相拉扯的派别、个人或优先级
relationships: 与其他势力的依赖、交换、竞争、敌意和误判
offscreen-action: 主角不在场时，它下一步会做什么，为什么现在必须做
protagonist-impact: 它会直接改变主角谁能接近、相信、保住或放弃什么
current-pressure: 本阶段逼它作出选择的具体压力
```

`public-goal` 是可供人物引用的表面理由，`true-interest` 才解释它在压力下为何不按口号行动。两者可以重合，但不能默认相同。`red-lines` 不是“永远不会做坏事”，而是“跨过哪条线会损害它必须保住的东西”。

### 内部派系要有真实分歧

内部派系不是给组织增加几个名字。每个重要分歧至少绑定一个不同的收益、风险或时间尺度：

- 谁希望保守维持现状，谁承担改变的收益与代价？
- 谁掌握决策资源，谁只掌握执行、泄密或拖延的杠杆？
- 各方对主角的价值、危险或可牺牲程度有何不同判断？
- 哪个外部事件会让原本的少数派突然获得筹码？

若所有成员都会无条件同意领袖，内部派系只是装饰；可以删掉，或把它转为真正的谈判压力。

### 关系要写成正在变化的交易

不要只写“友好/敌对/合作”。关系卡要能回答：

```text
A 需要 B 提供什么？
B 为什么暂时愿意给？
A 误以为 B 在意什么？
哪项资源、承诺或证据一变，关系就会改写？
```

本章可以只更新关系的一项：依赖增加、信任下降、交换变价、公开立场改变、内部裂缝暴露，或某方发现自己被误判。关系变化必须产生下一步的行动压力，而不是只更新标签。

## 三、离屏行动与势力网络

### 离屏行动测试

把主角暂时移出本章，问：**如果主角什么也不做，这个势力下一步仍会采取什么行动？**

答案应包含“触发—判断—动作—结果”：

```text
触发：资源短缺/内部派系施压/规则变动/外部敌意
判断：势力认为最先会失去哪项利益
动作：它选择施压、隐瞒、交易、撤退、替罪或公开表态
结果：某人的选择空间、价格或安全感发生变化
```

若没有离屏行动，势力大概率仍是背景名词。可以减少它的设定，也可以让它在主角到场前留下可观察的结果：缺席的人、改过的门锁、涨价的许可、被撤下的名字、提前流出的消息。

不要只写“如果主角不介入，势力将会怎样”的反事实说明。对本阶段承担主要压力的势力，至少选择一项已经启动或已经留下痕迹的动作，例如船位被扣、名单被撤、价格已经改动、使者已出发；其余势力再记录下一步即可。这样主角进入的是正在运行的局势，而不是等他出现才开始的设定。场景结束后，也要让至少一项势力行动继续执行、变价或被迫改道，不必另开一场戏解释。

规划阶段不必画完整世界地图，只标出本阶段真正影响主线的节点。每条关系边写“依赖什么、交换什么、谁更能承受中断”，即可发现主角的胜利是否只是因为其他人停止行动。

## 四、转译到章节与场景

### 场景前的动态卡

在现有章节控制卡之外，只补本场景真正需要的部分：

```text
relevant-rules: 影响本场选择的规则 ID
faction-move: 本场开始前哪方刚做了什么
protagonist-knowledge: 主角知道、误解或不知道什么
blocked-options: 哪些方案不可用，为什么
available-levers: 主角能调用的资源、关系或例外
counter-pressure: 阻力方不能满足主角的合理原因
choice-cost: 解决一个问题会损害什么
visible-signal: 读者通过什么动作/物件/对白感到世界在运转
state-change: 结束时规则执行、势力关系或选择空间怎样不同
```

不要把这张卡复制进正文。它的用途是防止“世界设定写了，但人物仍可随意行动”。

把抽象规则换成可感知的后果：资源稀缺落成错过、欠债或涨价；禁忌落成闭嘴、改称呼或流言；制度差异落成不同审核、时间和风险；势力竞争落成通路关闭、证词改变或关系站队。内部派系分歧也要通过一方给出帮助、另一方收回承诺等动作显影，不要只宣告“组织意见不一”。

## 五、反百科化与修订门

### 修订路由

- **`outline`**：冲突只靠临时事故，势力没有可解释的目标、资源和后续行动。
- **`character`**：主角面对规则却没有私人代价；阻力方的合理利益无法成立。
- **`scene`**：设定被解释了，但没有造成策略变化、关系变化或可观察后果。
- **`language`**：世界名词、历史说明或组织口号替代了人物在场的动作、对白和选择。

修订优先增加一个能改变选择的动作或后果，而不是继续增加历史、地理和组织层级。不要为制造冲突临时发明规则、秘密势力或不符合既有代价的例外。

## 六、最小验收清单

规划、写作或修订完成后，确认：

- [ ] 本章用到的每条规则都能说明范围、执行者和违反/遵守的代价。
- [ ] 相关势力同时有公开目标与真实利益，且二者在压力下可能冲突。
- [ ] 资源、约束、手段、红线和内部派系会产生具体行动，不只是形容词。
- [ ] 至少一个主要势力在主角到场前已有行动或可见痕迹，并且主角离场后仍有下一步；其结果会回到人物的选择空间。
- [ ] 势力关系通过交换、依赖、误判或公开行动变化，而不是只换标签。
- [ ] 世界信息落在动作、物件、身体反应、带立场的对白或可见后果中。
- [ ] 场景结尾留下的是改变后的处境或承接债，不是世界观总结。
- [ ] 没有为不影响本阶段选择的设定占用正文上下文。

如果某项失败，按 `references/revision-review.md` 的根因顺序处理；不要用“补一段设定说明”掩盖场景或人物问题。
