# 短中长篇规划工作流

## 输入处理

确认或保守推断：书名风格、题材与平台、主/副驱动、目标读者、核心情绪、主角目标、差异化设定、篇幅和复杂度。只有缺失信息会改变题材、平台、结局边界或核心受众时才暂停询问。

用户已经给出完整细纲时，检查它能否回答“谁在什么压力下作出什么选择，读者得到什么，哪些状态改变”。可以回答就直接进入写作，不重复规划；不能回答时只补缺口。

## 出版/投稿型项目启动门禁

当用户明确要求出版/投稿，且目标篇幅为 5 万字以上时，自动进入三章试写门禁；不要等全书规划完成后才验证可读性。三章试写使用同一固定主笔，按正式章节流程顺序完成，不因门禁临时更换写手。

门禁只检查可观察的阅读承诺，不用最低字数凑满：

- 标题的核心承诺、题材体验和主角的外部目标必须在前三章被看见；至少有一次具体行动或阻力，不得只写简介式宣言。
- 每章有一个主要读者回报和一个可复述的 `memory_point`；章节在局部闭合后自然停笔，不能用总结、复盘或新钩子补尾声。
- 三章能让读者说清主角要什么、当前付出什么、下一步为什么必须做；若只能复述规则而说不出目标，门禁不通过。
- 只记录篇幅作为规划证据，不设“低于某数即失败”的创作门槛；场景完成、回报兑现且自然收束时，短于预估应调整章纲，不回填水段。

三章通过后再扩展全书；未通过时按 `references/publication-readiness.md` 的根因路由返修。只有标题、题材、外部目标、主要人物关系或结局等重大方向需要改变时才询问用户，常规门禁失败由主 Agent 直接裁决和修订。

## 文风启动

- 新项目保留 `设定/文风档案.md`，默认 `status: inactive`，不把空模板当作正文约束。
- 需要建立本书独有声音时，按 `style-calibration.md` 用同一控制场景生成 A/B/C 匿名样稿；默认由隔离模型盲评并确定性汇总后提炼档案，不把样稿选择交给用户。
- 用户给出自有样稿、明确语言偏好或确认过的 accepted 章节时，也可按 `style-profile.md` 提炼可观察特征；用户明确选择时走人工覆盖兼容路径。
- 用户未要求文风定制时继续使用当前写作流程，不暂停规划，不追问模型名称。
- 模型版本由运行环境解析；项目只记录角色策略和稳定范围，具体见 `model-policy.md`。

## 读者契约

在 `设定/读者契约.md` 记录：

- `open_reason`：读者为什么会点开。
- `continue_reason`：什么持续变化使读者继续。
- `emotional_payoff`：主要情绪回报及允许的次要回报。
- `first_three_promises`：前三章各自展示的具体事件与题材体验。
- `midpoint_shift`：中段改变人物处境或读者理解的变局。
- `sustained_human_cost`：主角持续付出的个人代价，不能只剩工作量。
- `ending_payoff`：结局必须兑现或有意识拒绝的核心期待。
- `forbidden_substitutes`：不能拿来冒充题材兑现的套路，如临时反派、无关秘密、报告式成功总结。

这些字段描述阅读承诺，不是营销口号。每项都应能在正文事件中被观察到。

## 人物压力模型

为主要人物记录：

- `desire`：公开或自认的欲望。
- `fear`：人物会回避什么后果。
- `shame`：人物不愿被别人看见的自我判断。
- `debt`：金钱、人情、责任、承诺或历史负担。
- `contradiction`：同时成立、彼此拉扯的两种需求。
- `stress_behavior`：受压时的动作、坏习惯和判断偏差。
- `verbal_avoidance`：不愿直说什么，会怎样转移、反问或沉默。
- `private_agenda`：场景中不便公开的小目标。
- `legitimate_counter_interest`：与主角冲突但合理的利益。

不要把字段逐项解释进正文。它们用于产生行为差异、潜台词和有代价的选择。

## 篇幅策略

### 短篇

一次完成核心承诺、人物功能、完整结构、场景清单和结局兑现。人物压力只保留真正会进入场景的字段；中点和终稿各做一次阶段审查。

### 中篇

完成全书总纲和篇章级方向，详细规划当前篇章与后续 3–5 章。追踪人物代价、关键关系、读者回报轮换和有限待兑现项；每 5–6 章复盘。

### 长篇

固定全书方向、终局兑现和阶段边界；完整设计当前卷，滚动细化未来 5–10 章。每 8–10 章及卷末检查代价是否消失、人物是否同质、冷线是否被遗忘。

## 规划层级

1. 写读者契约和禁止用来冒充兑现的套路。
2. 选择主/副驱动及可见推进单位。
3. 建立主要人物压力模型与合理利益冲突。
4. 选择适合题材的结构，不默认三幕式。
5. 确定起点、终点、中段变局和结局兑现。
6. 设计篇章/卷功能、情绪变化、阶段成果与持续个人代价。
7. 为下一批章节生成可执行细纲和章节控制卡。

生成新一批细纲前先审计 `状态/待兑现.md`。每份章纲在 frontmatter 明确列出 `expectations-advanced`、`expectations-fulfilled` 与 `expectations-forbidden` 的稳定 ID，并用 `continuity-sources` 列出必须读取的角色、地点、规则、关系和时间线文件；允许前三组为空，但不得省略字段或用自由文本另起一套伏笔事实。首次埋钩记为 `planted`，后续回响记为 `reinforced` 或 `partial`，持续规则/代价记为 `active`，只有完整回收才记为 `fulfilled`。

每章细纲包含：核心事件、目标情绪、人物目标与选择、4–10 个可合并场景节拍、角色/关系/设定变化、读者回报、章内闭合、承接债和字数目标。场景数量按故事需要调整，不把固定数量当作门禁。

## 作品包装

新书规划或上架包装交付：

- 一句话卖点：主角 + 独特条件 + 核心行动 + 风险或收益。
- 作品简介：180–350 字，以题材承诺开场，不强制异常或谜团。
- 短简介：60–100 字。
- 标签：5–8 个。
- 前三章承诺：每章具体发生什么、目标读者得到什么。

关系、经营、日常和主题题材允许用人物吸引力、生活变化、情绪抵达或可见收益构成开篇承诺。

出版/投稿型项目的前三章门禁、固定主笔、三类隔离盲审和失败路由见 `publication-readiness.md`；本文件只保留规划层的入口条件，避免把验收细则复制成第二套事实。
