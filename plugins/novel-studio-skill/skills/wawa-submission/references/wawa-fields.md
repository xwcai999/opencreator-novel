# 蛙蛙投稿字段与规则缓存

> 本文件是非官方、可过期的本地参考，不替代登录用户对当前蛙蛙页面、账号、版权或最终提交的确认。缓存超过 7 天必须按“未实时复核”处理。

## 规则缓存元数据

每次使用前先比较当前日期与 `checked_at`；距 `checked_at` 超过 `stale_after` 的记录不得作为当前页面事实。

| 规则记录 | checked_at | source | confidence | stale_after |
|---|---|---|---|---|
| 公开页长篇正式签约提示：达到 10 万字方可正式签约 | 2026-08-12 | [蛙蛙写作投稿中心](https://wawawriter.com/app/submission) | high（公开页文字） | 2026-08-19（7 天） |
| 连载约 2 万、完结约 3 万的状态化表单观察值 | 2026-08-12 | 历史本地页面快照；非当前公开签约规则 | medium（历史观察） | 2026-08-19（7 天） |
| 字段、格式与大小快照 | 2026-08-11 | [投稿作品创建页](https://wawawriter.com/app/submission/create) | medium（页面快照） | 2026-08-18（7 天） |

当前日期超过对应 `stale_after` 时，输出必须写明“未实时复核”，并在实际页面重新核对后才能继续。即使未过期，缓存也不等于平台接受或签约保证。

## 页面字段（提交前实时核对）

| 字段 | 填写/核对要点 | 状态 |
|---|---|---|
| 作品/正文文件 | 常见快照支持 `.doc`、`.docx`、`.txt`，单文件不超过 50 MB；以当前页面为准 | 待实时复核 |
| 封面 | 常见快照支持 `.jpg`、`.png`、`.webp`，单张不超过 5 MB；以当前页面为准 | 待实时复核 |
| 作品名 | 对外展示书名，以页面最终保存值为准 | 必填，作者确认 |
| 笔名 | 对外展示笔名，只能由作者本人确认 | 必填，作者确认 |
| 投稿入口 | 选择页面提供的入口 | 必填，动态 |
| 作品分类 | 公开投稿提示主收长篇；页面入口可能变化 | 必填，动态 |
| 频道 | 男频、女频或全频等，以页面当前选项为准 | 必填，动态 |
| 作品状态 | 连载、完结或页面当前选项 | 必填，影响表单校验 |
| 三级类目 | 先从 `wawa-categories.json` 的固定完整路径选择；男/女频根须与频道一致，不能臆造或跨频道套用 | 必填，页面最终确认 |
| 标签 | 先从 `wawa-tags.json` 的固定候选选择；自定义标签另记，并以当前页面为准 | 必填，页面最终确认 |
| 简介 | 必须填写正式内容；长度以页面当前计数为准，常见快照为 ≤500 字 | 必填，需实测 |
| 历史成绩证明（可选） | 常见快照为 0 张或 1—10 张图片，单张 ≤5 MB；不得编造 | 可选，按需核验 |
| 自动解析字数 | 上传后由页面解析；本地估算不能替代 | 页面结果为准 |

扩展名、实际 MIME、文件大小和页面解析字数都需在页面上传后复核；仅改扩展名不视为格式转换。独立模式只能做本地检查，不能上传以取得页面解析结果。

## 固定分类与标签快照

`wawa-categories.json`（完整三级路径）和 `wawa-tags.json`（固定标签候选）是版本化离线参考，不是平台 API、官方永久规则或平台背书。分类快照记录公开创建页资源的提取信息；标签快照记录用户确认的页面状态。日常预检不联网、不静默修改快照；页面拒绝某值、快照无法覆盖作品或用户明确要求刷新时，停止将该值视为已确认，改由当前页面确认后再整体更新快照。

## 10 万正式签约与历史 2/3 万观察值（分层记录）

1. **公开页正式签约口径：**公开投稿中心文字写明长篇达到 **10 万字**方可正式签约。这是页面陈述，不是自动签约、接受或收益保证；提交前须在当前页面复核。
2. **历史表单观察值：**旧快照曾观察到选择“连载”时约需 **2 万字**、选择“完结”时约需 **3 万字**。这是状态化表单风险提示，来源和时效均弱于公开页，不得写成当前签约门槛。
3. 材料单分别填写“公开页正式签约口径”“历史表单观察值”“页面状态”“页面解析字数”“实际提示”。若两者冲突，保留冲突并要求实时核对，不自行合并或取代。

## 实时复核清单

使用已登录的目标账号打开当前创建/投稿页（本 Skill 不代为登录）：

1. 核对入口、字段名称、必填标记和文件限制是否变化。
2. 先以固定快照检查完整三级路径和标签：男/女频根必须匹配频道；自定义标签单独记录。页面拒绝快照值或没有准确路径时，暂停待人工确认，不临时凭记忆改填相似词。
3. 上传动作只能由用户在页面完成；以页面显示的格式、大小、解析字数和错误提示为准。
4. 分开记录 10 万公开页陈述与历史 2/3 万观察值，不能互相替代。
5. 复查书名、笔名、状态、类目、标签、简介与授权/版权选项；保存复核日期、页面 URL 和提示原文。

本文件不包含账号密码、token、截图、Logo、收益数据或真实稿件。
