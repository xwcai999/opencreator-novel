## 文件与图片限制

- 投稿正文：`doc`、`docx`、`txt`，单个文件 ≤ 50 MB。
- 执行就绪的长篇 TXT 采用本地稳定分章契约：UTF-8 无 BOM；章节标题逐行严格写成 `第1章 章名`，从 1 连续；禁止 Markdown `#`、三位补零、中文数字、缺号或重复编号。该契约用于避免页面无法解析章节，最终仍以页面回读为准。
- 封面：`jpg`、`png`、`webp`，单张 ≤ 5 MB。
- 历史成绩证明：0 张或 1—10 张；若上传，单张 ≤ 5 MB。
- 扩展名、实际 MIME、文件大小和页面解析结果都要在上传后复核；仅改扩展名不视为格式转换。

## 字数只记录，不作为本地预填门禁

签约口径、活动范围和页面状态校验不是同一层信息，不能互相替代。它们仅用于展示与页面回读：

1. **业务确认口径**：作者已确认长篇达到 **2 万字**作为签约/投稿入口的目标门槛。它表达目标，不代表平台一定签约，也不覆盖其他审核条件。
2. **页面状态化校验（当前代码/页面提示观察）**：选择“连载”时，解析字数需 **≥ 2 万字**；选择“完结”时，解析字数需 **≥ 3 万字**。这是提交按钮或状态提示可能实际拦截的条件。

填写材料时记录：`页面状态`、`页面解析字数`、`命中的校验提示`。用户主动触发预填即表示认可当前稿件字数；本地 Skill、执行引擎和管理页面不得因任何缓存字数范围阻止预填。若官方页面自身拒绝，原样记录提示并交由用户决定下一步，作品事实仍不得虚报。

## 用户业务门禁

- 作品简介必须提供正式内容且不超过 500 字。
- 即使页面技术上可能接受空值或自动写入“暂无简介”，本 Skill 也将空简介列为阻断项。

- 分类来源：官方[创建页](https://wawawriter.com/app/submission/create)当前加载的 `CreateSubmission.CD6Gp4cQ.js`，抓取时间为2026-08-19（Asia/Shanghai）。

- 投稿时直接从固定快照选择，不重复联网抓取。页面拒绝旧值、固定库无法覆盖作品或用户明确要求时，才执行整库刷新并重新验证。
- 作品频道与小说类目是两个独立字段。男频、女频作品要求分类根分别为男频、女频；全频作品允许使用固定树中的任一合法根路径。

## 实时复核原则

投稿前必须在已登录的目标账号中打开[创建页](https://wawawriter.com/app/submission/create)重新核对，不把本文件当作永久接口文档：

1. 重新确认入口是否仍为长篇、字段名称和必填标记是否变化。
2. 分类和标签从固定快照选择；若页面拒绝快照中的值，停止提交并标记“分类/标签快照待刷新”，不临时改填相似词。
3. 上传正文、封面和可选证明后，以页面显示的扩展名、大小、解析字数和错误提示为准。
4. 回读页面解析字数和状态提示；不在本地复刻页面字数门禁，也不把签约口径写成预填条件。
5. 检查简介非空且页面计数 ≤ 500；若计数规则与本地工具不同，以更严格者为准并记录差异。
6. 点击最终提交前复看书名、笔名、频道、状态、三级类目、标签及授权/版权选项；保存复核时间、页面 URL、错误提示或截图路径。页面正常接受固定值时不重新抓取候选库。
