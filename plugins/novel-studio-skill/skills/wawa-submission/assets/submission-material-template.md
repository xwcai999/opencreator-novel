# 蛙蛙投稿材料单（可复制填写）

> 本表只用于整理材料和本地预检；不代表已上传、已提交、平台接受或正式签约。蛙蛙写作与本项目无隶属关系。

## 使用模式与状态

- **集成模式**：可引用 `$novel-studio` 项目证据；仍需用户实时核对页面。
- **独立模式**：只提供元数据 JSON 与本地稿件；不需要、也不创建小说项目。
- **分类/标签快照**：`wawa-categories.json` 与 `wawa-tags.json` 只作离线、一致性预检；不是平台 API，页面最终保存值优先。
- **已知**：有文件、用户确认或仍在时效内的缓存证据。
- **待确认**：需要作者、账号或当前页面补充。
- **阻断**：本地字段/文件不满足预检，或页面证据过期/缺失。

## 5. 阻断项清单

任何一项未关闭都不要点击最终提交；本 Skill 默认不点击。

- [ ] 独立模式误要求项目目录，或集成模式缺少应有的 `$novel-studio` 证据。
- [ ] 正文缺失、格式不在 `doc/docx/txt`，或超过当前页面限制。
- [ ] 封面缺失、格式/大小不满足当前页面限制。
- [ ] 历史证明已提供但张数/大小不满足当前页面限制，或无法证明真实性。
- [ ] 作品名、笔名、投稿入口、频道或状态仍未确认。
- [ ] 三级类目不在固定完整路径、与频道根冲突、语义不匹配，或只是非官方示例词。
- [ ] 标签不在固定快照且未作为页面确认的自定义标签记录。
- [ ] 简介为空、使用“暂无简介”等占位内容，或超过当前页面计数。
- [ ] 页面解析字数与当前状态提示不符，或规则缓存已过期且未实时复核。
- [ ] 版权、授权、账号归属或最终提交人未确认。
